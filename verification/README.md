# 三维验证资料入口

本目录保留现行的三维复核入口；历史验证与评估文档未随本模板分发。

这些文档记录当时的实现、检查结果与实验，不能作为本次代码通过验证的证明。视觉参数和已撤回实验的适用顺序见 [DESIGN.md](../DESIGN.md)，博客维护边界见 [AGENTS.md](../AGENTS.md)。

实际复核仍使用仓库根目录的 `scripts/check-*.mjs` 与 `reference/` 对照页面；归档没有移动模型、截图、音频、测试脚本或开发页面。运行方式和最低验证要求见[维护手册](../BLOG-MAINTAIN-PERFECT.md)及 AGENTS.md；本地参考视频、帧图和工具可能需另行准备。
