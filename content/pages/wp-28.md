*这是一个示例独立页面。把内容换成你自己的介绍即可，路径与系统路由不要冲突。*

## 本站怎么构成

本站用 Markdown 写作、Git 管理源码，由 Astro 生成静态页面，Pagefind 提供全文检索；三维界面作为独立的 `/lab/` 入口，普通文章不加载 Three.js 或任何三维资源。

| 部分 | 位置 | 说明 |
| --- | --- | --- |
| 正文 | `content/posts/`、`content/pages/` | 唯一内容来源 |
| 博客 | `apps/blog/` | Astro 页面、布局与样式 |
| 三维入口 | `src/`、`lab/` | 构建到 `dist/lab/` |
| 构建与发布 | `scripts/blog/`、`ops/` | 校验、打包、上传与回滚 |

## 写作流程

1. 在 `content/posts/` 新建 Markdown，按 `content/README.md` 填写 frontmatter。
2. `npm run check:content` 校验字段、路径与主题引用。
3. `npm run build` 生成博客、`/lab/` 与搜索索引。
4. `npm run preview` 本地检查阅读、导航、搜索与 404。

## 排版能力

正文支持 CommonMark 与 GFM。中文标点后的强调同样生效（由 `remark-cjk-friendly` 处理）：

> **中文加粗：**后面接文字也能正确渲染成强调。

```js
const sections = ["posts", "pages"];
export const isPublic = (doc) => !doc.draft;
```

- 列表、表格、引用与脚注[^fn]都有对应的直角样式
- 代码块使用 JetBrains Maple Mono 子集
- 正文与界面字体为 MiSans

[^fn]: 脚注由阅读层统一排版，实现见 `src/article-reader*.ts`。
