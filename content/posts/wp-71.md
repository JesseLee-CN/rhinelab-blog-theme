**清晨**

*示例说明：这一段用斜体演示强调样式；正文整体可以替换成你自己的随笔。*

　　天亮得很慢。先是窗框的轮廓，然后是桌面上那层薄灰，最后才是颜色。城市在窗外一点点恢复重量，像有人把音量旋钮缓慢转回原位。

　　写下来的意义或许只在于此：把当时的光线、气味和判断留在原处，好让以后那个更忙、更笃定的自己有机会回头核对一次。

- 一篇短文也值得独立成页：每篇文章都有规范地址，禁用 JavaScript 或 WebGL 仍可阅读
- 分类与标签会同时出现在分类页、RSS 与搜索索引里
- 三维档案里的卡片摘要取自同一份 `description`

代码与表格在短随笔里同样可用：

```bash
npm run check:content   # 新增或修改文章后先校验
npm run build           # 再生成博客与 /lab/ 入口
```
